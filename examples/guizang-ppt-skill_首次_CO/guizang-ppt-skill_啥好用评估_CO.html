guizang-ppt-skill 是一个生成单文件 HTML 横向翻页网页 PPT 的 skill。它主要基于两套预设视觉模板（电子杂志风、瑞士国际主义风），通过拷贝模板、填充内容和选定主题色完成一份可翻页演示文稿。最终用户可以得到一份不需要安装软件、浏览器直接打开的单文件 HTML 演示文稿。经评估，guizang-ppt-skill 更适合线下分享、产品发布这类叙事感强的演讲场景。

2这个 Skill 是啥

guizang-ppt-skill 是一个帮你把文章或大纲做成单文件网页 PPT 的 skill，主要依赖两套锁定的视觉模板（电子杂志风、瑞士国际主义风）和一套翻页交互脚本，通过需求澄清、拷贝模板、填充内容和选定主题色完成一份可翻页演示文稿，主要服务需要做线下分享、产品发布或带个人风格演讲的用户。

1使用方法

  • 把文章、大纲或研究内容做成叙事型分享 PPT 时可以用
  • 需要制作发布会、demo day 风格的演示文稿时也能用
  • 给一份大纲或素材文档，加上想要的风格和配色即可
  • 有截图或产品图时可以说明落位比例，会一起处理

2任务步骤

  1. 先回答风格、受众、时长等问题，对齐版式方向
  2. 拷贝对应风格的模板文件，选定一套主题色
  3. 把内容填进对应版式，检查类名是否都有样式定义
  4. 需要配图时可选生成信息图或截图美化

3额外需要

  • 除 AI agent 本身外，推荐安装方式需要 Node.js 环境
  • 想用配图功能需要额外的图片生成模型访问权限

4最后交付

  • 一份单文件 HTML 网页 PPT，浏览器直接打开翻页
  • 可选生成配套的配图或多平台封面图

3这个 Skill 好用吗

好用度：7.3/10

完整度高，文档、踩坑清单和赞助背书都很齐全，项目本身维护活跃。好用度较高，核心免费、风险低，但填充内容这一步容易因为类名对不上样式而返工。优势和不足相比，优势的权重更大，主要门槛是可验证性只有一般，官方推荐的一键安装方式有一个已知未修复的漏装 bug。

好用之处

  • guizang-ppt-skill 的两套视觉系统做出来的 PPT 质感很精致，不用自己写 CSS 或调版式。
  • 它是单文件 HTML，浏览器直接打开就能翻页演示，不需要装额外软件。
  • 项目维护活跃、有多家企业赞助，踩坑清单把常见问题都记录下来了。

可能卡住

  • guizang-ppt-skill 明确说不适合大段表格数据和高信息密度内容。
  • 它官方推荐的一键安装方式目前有已知 bug，会漏装模板和参考文件。
  • 它只提供 5+4 套固定预设配色，不支持自定义品牌色或企业模板。

4这个 Skill 适合你吗

适合度：5.9/10

guizang-ppt-skill 部分匹配你的需求。如果你的行研报告以叙事分享为主、不涉及大段数据表格，可以安装。

适合场景

  • 把行业观察或研究内容做成叙事型的分享 PPT
  • 线下分享、产品发布或带个人风格的演讲场合
  • 接受固定配色方案、不需要企业品牌定制的场景

不适合场景

  • 报告里有大段表格数据或高信息密度内容
  • 需要团队多人协作编辑同一份 PPT
  • 需要导出成可在 PowerPoint 里编辑的 PPTX 格式

5使用节奏建议

  1. 第一次先拿一篇不太复杂的文章试做 7 页左右的 PPT，看效果和返工量。

  3. 遇到样式跑偏时，先按官方 checklist 检查类名是否都有定义。

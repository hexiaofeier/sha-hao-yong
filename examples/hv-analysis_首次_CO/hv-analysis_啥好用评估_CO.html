2这个 Skill 是啥

hv-analysis 是一个帮你系统性研究陌生产品、公司、概念或人物的 skill，主要依赖当前 AI agent 自带的联网搜索能力和本地 Python 转 PDF 脚本，通过并行调研、纵向历程梳理和横向竞品对比完成研究任务，主要服务需要在决策或写作前快速摸清一个陌生对象来龙去脉的用户。

1使用方法

  • 想提前系统性搞懂一个陌生公司、产品或概念时可以用
  • 写作或调研前需要系统性素材准备时也能用
  • 给一个研究对象名称即可，比如公司名或产品名
  • 有特别关注点可以补充说明，没有也能直接开始

2任务步骤

  1. 先联网收集纵向历程和横向竞品信息，多来源交叉核实
  2. 写纵向叙事，讲清楚从诞生到现在的发展脉络
  3. 写横向对比，把主要竞品逐一摆出来分析
  4. 交叉两条线，给出独到判断和三种未来推演
  5. 转换成排版精美的 PDF 交付

3额外需要

  • 除 AI agent 本身外，生成 PDF 还需要装两个软件包
  • Windows 上这两个包还依赖 GTK 运行库才能正常出图
  • 研究学术类对象时会额外调用 arxiv 公开接口，不需要账号

4最后交付

  • 一份 10,000—30,000 字的横纵分析研究报告
  • 报告末尾附完整的信息来源清单，方便核对

3这个 Skill 好用吗

好用度：7.3/10

完整度较高，SKILL.md 写作规范和质检清单都很详尽。核心检索免费、风险也低，但生成一份报告很吃 Token，PDF 转换还要多装一步系统依赖。优势和不足相比，优势的权重更大，主要门槛是可验证性只有一般，skill 本身三个多月没有更新过。

好用之处

  • hv-analysis 把纵向历史脉络和横向竞品对比结合起来，比单纯问一句“这是什么”能看到更深的判断。
  • 它不需要额外注册账号或申请 API Key，联网检索全部用 AI agent 自带能力完成。
  • 它自带完整的 PDF 排版脚本，出来的报告可以直接分享，不用自己再排版。

可能卡住

  • hv-analysis 生成一份完整报告耗时长、很吃 Token，不适合想要马上拿到答案的场景。
  • 它依赖 AI agent 自身的联网搜索质量，已经有用户反馈遇到过搜索结果为空的情况。
  • 它在 Windows 上装 PDF 转换依赖时，还需要额外装 GTK 运行库，容易卡在这一步。

Token 消耗高固定常规任务：多个子 Agent 并行联网搜索、多轮关键词调整，加上写一份 10,000—30,000 字的长报告，消耗明显偏高。
风险值低固定常规任务只会把研究对象名称这类公开查询词发给 AI agent 自带的搜索能力，不需要账号或权限；PDF 生成在本地完成，不涉及自动发布或不可逆操作。

4这个 Skill 适合你吗

适合度：7.8/10

适合场景

  • 提前系统性了解一个陌生公司、产品或概念

  3. 遇到搜索结果为空、报告内容单薄时，检查一下当前 AI agent 的联网能力是否正常。

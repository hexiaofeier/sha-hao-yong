2这个 Skill 是啥

啥好用 Skill 是一个帮你在安装候选 Skill 前先摸清楚它是啥、好不好用、适不适合你的 skill，主要依赖当前 AI agent 自带的文件读取和联网能力，加上一个纯 Python 标准库脚本做校验和排版，通过锁定固定常规任务、收集公开证据、按固定公式打分完成评估，主要服务经常要海选、筛选大量候选 Skill 的用户。

1使用方法

  • 拿不准一个候选 Skill 值不值得装时可以用
  • 同时海选好几个同类 Skill、要快速筛选时也能用
  • 给一个候选 Skill 的链接、压缩包或文件夹即可
  • 结合具体需求评估，或按一般目标场景评估都行

2任务步骤

  1. 先选评估方式：结合具体需求，还是按一般场景
  2. 从候选对象的官方材料里锁定一条固定常规任务
  3. 只读翻官方文档和公开数据，不运行候选代码
  4. 按固定公式给好用度和适合度打分，算出推荐度
  5. 校验通过后生成单文件 HTML 说明书

3额外需要

  • 除 AI agent 本身外，只需要本机装好 Python 3
  • 渲染脚本只用标准库，不用装第三方依赖

4最后交付

  • 一份单文件 HTML 版的安装前说明书
  • 报告末尾附来源清单和尚不能确认的事项
